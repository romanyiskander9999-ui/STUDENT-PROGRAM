التشغيل من المصدر: ثبّت Python 3.12 ثم نفّذ:
  python -m pip install -r requirements.txt
  python student_manager.py

إنشاء مثبت Windows: شغّل build_windows.bat على Windows، أو اتبع الخطوات المصورة نصيًا في GITHUB_BUILD_AR.txt لرفع المشروع وتشغيل GitHub Actions.

تنبيه خصوصية: قاعدة البيانات غير مشفرة ولا تتطلب كلمة مرور حسب طلب المستخدم. احمِ حساب Windows والجهاز، ولا ترفع بيانات الطلاب الحقيقية إلى المعاينة العامة أو خدمات غير معتمدة. احتفظ بنسخ احتياطية في مكان آمن.

النماذج والتقارير داخل البرنامج أدوات تنظيمية، وليست بديلاً عن النماذج الرسمية المعتمدة من وزارة التربية والتعليم.


التشغيل السريع على Windows: افتح الملف RUN_PROGRAM.bat أو تشغيل_البرنامج.bat الموجود بجوار هذا الملف. إذا لم يظهر الملف، تأكد من فك ضغط الأرشيف بالكامل وليس فتحه كمعاينة فقط.
