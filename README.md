# مدير شئون الطلاب Pro 2026/2027 — v2.3

هذا المستودع يحتوي على مصدر برنامج Windows المبني باستخدام Python وTkinter وSQLite.

## استعادة ملفات المصدر

حزمة المصدر محفوظة في `.sourcebundle/` على هيئة أجزاء Base64 لتسهيل نقل الملفات. يقوم GitHub Actions بتجميع الأجزاء وفك أرشيف المصدر تلقائيًا قبل الاختبار والبناء.

## البناء والتحقق

- افتح تبويب **Actions** وشغّل **Build Windows installer**، أو ادفع تحديثًا إلى `main`.
- يتم استعادة ملفات المصدر، تثبيت المتطلبات، فحص صياغة Python، وتشغيل اختبارات قاعدة البيانات.
- عند نجاح الاختبارات يتم إنشاء `StudentManagerPro2026.exe` ثم مثبت `StudentManagerPro_Setup.exe`.
- ملف التثبيت يظهر ضمن **Artifacts** في تشغيل الـ workflow.

## تشغيل محلي

بعد فك حزمة المصدر:

```powershell
py -3 -m pip install -r requirements.txt
py -3 -m unittest -v test_store.py
build_windows.bat
```

## حماية بيانات الطلاب

لا تُرفع قواعد بيانات الطلاب أو ملفات النسخ الاحتياطي إلى هذا المستودع. قاعدة البيانات محلية على جهاز المدرسة، وملفات `*.db` و`*.sqlite*` مستثناة في `.gitignore`.
