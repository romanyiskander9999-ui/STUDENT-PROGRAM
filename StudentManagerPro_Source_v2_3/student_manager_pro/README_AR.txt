مدير شئون الطلاب Pro — الإصدار 2.3 | العام الدراسي 2026/2027

برنامج مكتبي محلي لإدارة بيانات الطلاب والحضور والدرجات والسلوك والتقارير.
لا توجد كلمة مرور أو آلية تفعيل. الإصدار الحالي 2.3. تحفظ البيانات على جهاز المدرسة داخل مجلد المستخدم.

أهم الوظائف:
- إضافة وتعديل وحذف وبحث الطلاب وتصفيتهم حسب الصف والفصل.
- استيراد وتصدير ملفات Excel.
- سجل حضور يومي يعرض جميع الطلاب مع تصفية الصف والفصل والتاريخ.
- تسجيل الحالة لطالب أو لعدة طلاب، وتسجيل الفصل كله حاضراً أو غائباً بعد التأكيد.
- ملخص يومي لأعداد الحضور والغياب والتأخير والإذن والغياب بعذر وغير المسجل، مع ملاحظات لكل حالة.
- تصدير كشف الحضور اليومي شاملاً الطلاب غير المسجلين بصيغة CSV متوافقة مع Excel.
- كشف حضور شهري أو سنوي حسب الصف والفصل، مع عدد أيام التسجيل وحالات الحضور والغياب ونسبة الحضور من الأيام المسجلة، وتصدير CSV ومعاينة للطباعة.
- سجلات الدرجات والسلوك والتقارير.
- نماذج طلب قبول وإعادة قيد وتحويل، تُملأ تلقائياً من ملف الطالب وتفتح للطباعة مع أماكن التوقيعات.
- الملف الشامل للطالب ويجمع البيانات الشخصية والحضور والدرجات والسلوك والتحويلات وسجل التعديلات والترحيل.
- سجل تاريخي آلي لتغييرات البيانات مع القيمة القديمة والجديدة وتاريخ التعديل.
- سجل تواصل مستقل مع ولي الأمر: تاريخ التواصل ووسيلته وسببه ونتيجته والملاحظات وموعد المتابعة واسم المسؤول.
- تقرير يربط حالات الغياب المتكرر بسجل إخطار ولي الأمر، ويميّز بين تم التواصل ومحاولة دون رد ولم تتم المتابعة، مع التصفية والتصدير إلى CSV.
- سجل التواصل ظاهر أيضاً ضمن الملف الشامل للطالب، ويحذف تلقائياً مع حذف ملف الطالب.
- ترحيل طالب محدد أو جميع طلاب صف/فصل إلى صف وفصل جديد مع توثيق القرار والعام الدراسي.
- سجل طلبات التحويل والنقل بين المدارس مع الحالة والملاحظات، وإدراجها في التقارير.
- بطاقات الطلاب مع QR يحتوي كود الطالب فقط، ولا يضم الاسم أو الصف أو الفصل.
- نسخ احتياطي ذري إلى ملف مؤقت مع فحص النسخة قبل اعتمادها، واستعادة بعد فحص سلامة الملف، مع حفظ نسخة أمان تلقائية من قاعدة البيانات السابقة قبل الاستبدال.

التشغيل من المصدر: ثبّت Python 3.12 ثم نفّذ:
  python -m pip install -r requirements.txt
  python student_manager.py

إنشاء مثبت Windows: شغّل build_windows.bat على Windows، أو اتبع الخطوات المصورة نصيًا في GITHUB_BUILD_AR.txt لرفع المشروع وتشغيل GitHub Actions.

تنبيه خصوصية: قاعدة البيانات غير مشفرة ولا تتطلب كلمة مرور حسب طلب المستخدم. احمِ حساب Windows والجهاز، ولا ترفع بيانات الطلاب الحقيقية إلى المعاينة العامة أو خدمات غير معتمدة. احتفظ بنسخ احتياطية في مكان آمن.

النماذج والتقارير داخل البرنامج أدوات تنظيمية، وليست بديلاً عن النماذج الرسمية المعتمدة من وزارة التربية والتعليم.


التشغيل السريع على Windows: افتح الملف RUN_PROGRAM.bat أو تشغيل_البرنامج.bat الموجود بجوار هذا الملف. إذا لم يظهر الملف، تأكد من فك ضغط الأرشيف بالكامل وليس فتحه كمعاينة فقط.


الإصدار 2.0 — نماذج شئون الطلاب
- نماذج قابلة للطباعة لطلب القبول وإعادة القيد والتحويل، مع تعبئة بيانات الطالب تلقائياً.
- إضافة خانات سبب الطلب والتوقيعات والتاريخ ورقم الطلب.
- النماذج تنظيمية ويجب مطابقتها مع النماذج الرسمية المعتمدة قبل الاستخدام الرسمي.

الإصدار 1.7 — إضافات القيد والمستندات
- سجل القيد وإعادة القيد والانقطاع وترك المدرسة، مع التاريخ والعام الدراسي والسبب ورقم القرار والملاحظات.
- أرشيف مستندات مستقل لكل طالب: إرفاق وفتح وحذف المستندات. تحفظ الملفات محلياً داخل مجلد StudentManagerPro/documents.
- تقرير حالة القيد مع التصفية والتصدير إلى CSV.
- تمت إضافة الجداول الجديدة دون حذف أو إعادة إنشاء جداول الإصدارات السابقة.

تشغيل البرنامج: افتح مجلد student_manager_pro ثم شغّل RUN_PROGRAM.bat أو تشغيل_البرنامج.bat.


الإصدار 2.0 — التقارير الإحصائية وحماية المستندات
- إضافة إحصاءات القيد حسب الصف والفصل للعام الدراسي المحدد، مع عرض إجمالي المقيدين والمنقطعين وتاركي المدرسة.
- إضافة كشوف المقبولين/المقيدين وكشف المنقطعين وتاركي المدرسة ضمن مركز التقارير، قابلة للمعاينة والطباعة والتصدير إلى Excel.
- اعتماد آخر حركة للطالب داخل العام الدراسي عند احتساب حالته، لمنع تكرار الطالب في الإحصاءات بسبب تعدد الحركات.
- تعزيز أمان أرشيف المستندات برفض المسارات الخارجة عن مجلد الطالب، واستخدام أسماء ملفات فريدة، وتنظيف الملف المنسوخ إذا فشل حفظ بياناته.
- حذف مجلد مستندات الطالب المحلي عند حذف ملف الطالب بعد نجاح حذف السجلات من قاعدة البيانات.
- إضافة اختبارات لحساب آخر حالة، والتجميع حسب الصف والفصل، والتحقق من مسارات المستندات.


الإصدار 2.0 — كشوف الحضور الشهرية والسنوية
- إضافة تقرير شهري أو سنوي حسب الصف والفصل.
- إظهار أعداد حاضر/غائب/متأخر/إذن/غياب بعذر لكل طالب، والطلاب الذين لم تسجل لهم حالات.
- حساب نسبة الحضور من أيام التسجيل الفعلية فقط، وعدم افتراض أيام دراسة غير مسجلة.
- تصدير CSV ومعاينة HTML قابلة للطباعة.


الإصدار 2.1 — متابعة الغياب المتكرر
- إضافة تقرير متابعة للطلاب الذين يتجاوزون حد الغياب الكلي أو حد الغياب المتتابع.
- حدود التنبيه قابلة للتعديل عند عرض التقرير، والقيم الافتراضية 5 أيام غياب بدون عذر و3 أيام غياب متتابعة.
- إظهار بيانات ولي الأمر والهاتف لتسهيل المتابعة، مع التصفية حسب الصف والفصل.
- التتابع محسوب من أحدث حالات الحضور المسجلة المتتابعة، وليس من أيام التقويم؛ ولا تُعامل أيام الغياب بعذر كغياب بدون عذر.
- دعم تصدير نتائج المتابعة إلى CSV متوافق مع Excel.


الإصدار 2.3 — التواصل مع أولياء الأمور
- سجل موثق لمحاولات الاتصال والمقابلات والرسائل والخطابات مع أولياء الأمور.
- تسجيل نتيجة التواصل وسبب الإخطار والملاحظات وموعد المتابعة واسم المسؤول.
- تقرير متابعة إخطار أولياء الأمور للطلاب ذوي الغياب المتكرر، مع تمييز الحالات التي لم تتم متابعتها.
- تصدير سجل التواصل وتقارير المتابعة إلى CSV متوافق مع Excel.


الإصدار النهائي 2.3 — مراجعة الاعتمادية
- تم تعزيز النسخ الاحتياطي والاستعادة، والتحقق من سلامة ملف قاعدة البيانات قبل الاستعادة.
- لا يستبدل البرنامج قاعدة البيانات الحالية بملف غير صالح، ويحفظ نسخة أمان قبل الاستعادة.
- تم اختبار الترحيل من قاعدة بيانات أقدم بإضافة الجداول الناقصة دون حذف بيانات الطلاب الموجودة.
- اجتاز المشروع 33 اختبار وحدة في بيئة التطوير.
- ملف التثبيت التنفيذي يحتاج بناءً على Windows عبر build_windows.bat أو GitHub Actions؛ ملف ZIP الحالي يحتوي المصدر وملفات البناء ولا يحتوي Setup.exe مبنياً.
